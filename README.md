# ScoopBucket

Scoop manifests for Abhinav Prabhakar's command-line tools: Grain, Wordy,
LittleClaw, Unstop, Whatschedule, and AnnasArchiveMCP.

```powershell
scoop bucket add abhinav https://github.com/Abhinav-Prabhakar/ScoopBucket
scoop install grain
```

Replace `grain` with `wordy`, `littleclaw`, `unstop`, `whatschedule`, or
`annas-archive-mcp`.
